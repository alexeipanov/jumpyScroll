jumpyScroll

Overview

javascript plugin for quick document scroll with animation

Github repository

Features

  • 5 basic css animations
  • 75 advanced animations with Animate.css
  • custom events
  • custom animations
  • touch-enabled
  • pure JS - no JQuery needed

Requirements

  • (optional) Animate.css

Installation

Include CSS

<link rel="stylesheet" href="jumpyscroll.css">

Include JS

<script src="jumpyscroll.min.js"></script>

Set up HTML

<body>
    ...
    <section>
        page one
    </section>

    <section>
        page two
    </section>

    <section>
        page ..
    </section>

    ...
</body>

Call the plugin

document.addEventListener('DOMContentLoaded', function() {
    window.jumpyScroll();
});

or, with JQuery:

$(document).ready(function(){
    window.jumpyscroll();
});
